Featured Case Study

Vibration Anomaly Detection

Real-Time Edge AI Vibration Anomaly Detection

Problem: Predictive maintenance needs vibration analysis and anomaly classification running directly on a resource-constrained MCU — filtering, FFT, feature extraction, and inference all in one deterministic pipeline, not offloaded to a server.
Solution: Built and validated an embedded Edge AI pipeline — DSP filtering, FFT spectral analysis, feature engineering, and a quantized INT8 neural network — architected for ARM Cortex-M/STM32-class targets, with a Python reference implementation used to cross-validate the embedded C core.
C99 / ARM Cortex-M FreeRTOS TinyML

System Workflow:
• Signal Processing: Vibration signal filtered, windowed, and transformed via FFT for spectral analysis.
• Feature Extraction: Seven engineered vibration features computed per window.
• On-Device Inference: A compact 7-16-3 MLP, quantized to INT8, classifies machine condition.
• Validation: Cross-language golden-vector testing keeps the Python reference and embedded C implementation in agreement.

Engineering Approach

How I Approach Firmware

Principles that shape how I design and deliver embedded systems.

Fault-Aware Architecture

Designing firmware with deliberate fault handling — watchdogs, defined recovery paths, and deterministic state machines — so failure modes are anticipated instead of discovered in the field.

Resource-Conscious Optimization

Profiling memory, power, and CPU budgets on constrained microcontrollers before optimizing — so effort goes toward changes that actually move the numbers.

Maintainable Architecture

Modular drivers, clear interfaces, and documented decisions, so the firmware I hand off can be extended and maintained by your team, not just by me.

I am an Electrical Engineer working at the intersection of embedded systems, firmware, and Digital Signal Processing. My hands-on experience spans ARM Cortex-M platforms, real-time firmware development on Zephyr RTOS, and embedded communication protocols — bridging embedded systems and real-time data processing.
